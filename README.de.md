# Public Records — Automatisierungsrezepte

Lauffähige Beispiele, die [Public Records](https://apify.com/publicrecords)-Apify-Actors **auf deinem Apify-Konto** aufrufen. Setze `APIFY_TOKEN` (oder das Geheimnis der Plattform) auf dein eigenes Token. Nicht committen.

Siehe auch die 17 n8n-Workflows und Make-/Zapier-/Pipedream-/Activepieces-/Clay-HTTP-Rezepte in [`publicrecords-mcp/templates`](https://github.com/GeminiGeorge22/publicrecords-mcp/tree/main/templates).
