# Public Records — recetas de automatización

Ejemplos listos para ejecutar que llaman a los Actors de [Public Records](https://apify.com/publicrecords) en Apify **en tu cuenta de Apify**. Define `APIFY_TOKEN` (o el secreto de la plataforma) con tu propio token. No lo subas al repositorio.

También puedes ver los 17 flujos de n8n y las recetas HTTP de Make / Zapier / Pipedream / Activepieces / Clay en [`publicrecords-mcp/templates`](https://github.com/GeminiGeorge22/publicrecords-mcp/tree/main/templates).
