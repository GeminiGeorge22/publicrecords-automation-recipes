# Public Records — receitas de automação

Exemplos prontos para executar que chamam os Actors da [Public Records](https://apify.com/publicrecords) no Apify **na sua conta da Apify**. Defina `APIFY_TOKEN` (ou o segredo da plataforma) com o seu próprio token. Não o envie no repositório.

Veja também os 17 fluxos n8n e as receitas HTTP de Make / Zapier / Pipedream / Activepieces / Clay em [`publicrecords-mcp/templates`](https://github.com/GeminiGeorge22/publicrecords-mcp/tree/main/templates).
